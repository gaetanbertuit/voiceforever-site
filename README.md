# Site public de VoiceForever

Page de présentation et politique de confidentialité de l'application iPad **VoiceForever**,
publiées par GitHub Pages.

Le contenu est généré depuis le dépôt privé de l'application : la politique de confidentialité
est dérivée de `Sources/VoiceForeverPad/PadPrivacyPolicy.swift` par `scripts/build-site.py`,
afin que l'écran affiché dans l'app et la page publiée ne puissent pas diverger.

Ne pas modifier `confidentialite.html` ici : la modification serait écrasée à la prochaine
génération.
